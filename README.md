# Buscador de CNPJ

Um pequeno projeto Node/Next.js que permite buscar informações de CNPJ via API pública.

## Como usar
1. Clone o repositório
2. Instale as dependências com `npm install`
3. Rode o servidor com `npm run dev`
4. Acesse `http://localhost:3000` e insira o número do CNPJ.
